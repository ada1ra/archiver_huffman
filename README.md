### Цель кейса
Создать консольное приложение для сжатия и восстановления файлов без потерь на основе алгоритма Хаффмана:
- читать и анализировать частоты байтов входного файла
- строить оптимальные префиксные коды с помощью бинарного дерева
- выполнять упаковку в битовый поток с сохранением заголовка (таблицы частот)
- выполнять распаковку с восстановлением исходных данных
Провести экспериментальное исследование степени сжатия и производительности на различных типах данных
