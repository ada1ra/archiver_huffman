### Цель кейса
Создать консольное приложение для сжатия и восстановления файлов без потерь на основе алгоритма Хаффмана:
- читать и анализировать частоты байтов входного файла
- строить оптимальные префиксные коды с помощью бинарного дерева
- выполнять упаковку в битовый поток с сохранением заголовка (таблицы частот)
- выполнять распаковку с восстановлением исходных данных
Провести экспериментальное исследование степени сжатия и производительности на различных типах данных

### Реализованные возможности
- Поддержка любых бинарных файлов (алфавит 256 байт)
- Оптимизированный заголовок: записываются только ненулевые частоты (HdrSparse)
- Битовые операции для упаковки/распаковки кодов переменной длины
- Корректная обработка пустых файлов и файлов с единственным уникальным символом
- Модульная структура: `huffman.h`, `huffman.c`, `main.c`
- Интерфейс командной строки

### Сборка и запуск
```bash
# Компиляция
gcc -O2 -Wall -Wextra -o huffman main.c huffman.c
# Сжатие файла input.txt
./huffman -c input.txt compressed.bin
# Разжатие файла
./huffman -d compressed.bin output.txt
```
